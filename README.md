## Overview

MelodicFlow harmonizes incoming MIDI notes into chords, quantizes them to selected scales and keys, and generates companion melody voices for rapid harmonic sketching in any DAW.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **MelodicFlow** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Key Lock** | Quantize MIDI input to any key and scale in real time |
| **Chord Harmonizer** | Generate up to four harmony voices above each played note |
| **Inversion Control** | Select chord voicing inversions for smooth voice leading |
| **Octave Range** | Set harmony voice octave range for close or wide voicings |
